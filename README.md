# Riff

Early research and ideation for an open-source server/networking project inspired by NGINX, Tomcat, and Netty.

**Status:** ideation only; no runtime is implemented. The project name is Riff.

Proposed starting point: an embeddable HTTP runtime with explicit resource limits and useful explanations of overload and latency. Product layer, language, and architecture remain open decisions.

Start with [the ideation index](ideation/README.md). Original repository content is available under the [MIT license](LICENSE).

Name selected on 2026-09-15: **Riff**. See [research and product analysis](docs/README.md) and [naming history](ideation/06-naming-exploration.md).
